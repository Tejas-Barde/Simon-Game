# 🎮 Simon Game

A web-based Simon Game built using **HTML**, **CSS**, and **JavaScript**. Test your memory by repeating an increasingly complex sequence of colors. Can you keep up?

## 🛠️ Tech Stack

- **HTML**: Structure of the game.
- **CSS**: Styling and layout.
- **JavaScript**: Game logic and interactivity.

## 🎮 How to Play

1. Press any key to start the game.
2. Memorize the color sequence shown.
3. Click the buttons in the same order.
4. With every correct round, the sequence gets longer.
5. One wrong click and the game resets!
